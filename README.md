VersantProVersantPro is a browser-based English fluency and Versant-style practice platform for learners, students, and job candidates. It provides focused practice modules, learner guidance, feedback collection, and an administrative content workspace.Verification for ChatGPT – June 2026This README documents the current project structure, public practice workflow, administrative content workflow, and security expectations for the VersantPro website.Project PurposeVersantPro is designed to help learners practise English skills in short, structured sessions. Each module focuses on a specific ability instead of presenting one large, difficult assessment. Learners can practise independently in a browser and return to a module when they want to improve a particular skill.The website is intended for practice and preparation. It is not an official Pearson Versant test, score report, certification service, or replacement for an official assessment.Practice ModulesThe public website includes the following learner-facing areas:Module Purpose
Jumble Words Listen to up to four short phrases once, reconstruct one complete sentence, and write it within 30 seconds after the audio ends.
Repeat Listen to a sentence and practise repeating it clearly.
Conversation Respond to practical English prompts using clear, organised answers.
Dictation Listen carefully and type the sentence with accurate spelling and punctuation.
Fill in the blanks Complete context-based sentences with the correct word or adjective.
Passage Read or process a passage, write a response, and review key-idea coverage.
Dictionary Look up words, meanings, examples, and related language support.
Tips Read practical guidance for improving fluency, listening, vocabulary, grammar, and response structure.
