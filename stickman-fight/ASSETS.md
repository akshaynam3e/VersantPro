# Assets

**Art direction:** Premium neon cyberpunk arcade arena. Dark navy grid space, cyan player energy, hot-magenta rival energy, crisp white HUD type, subtle electric particles, and procedural black stickman fighters with emissive edge accents. The camera is a clean side-on 2.5D game-engine view with no photorealistic objects.

## Bundled assets
- `client/public/assets/versantpro-stickman-reference.png` — visual target reference.
- `client/public/assets/versantpro-arena-texture.png` — arena background texture used by the game.

The game uses local assets so the repository can be pushed to GitHub and deployed independently. Fighters, platform, grid, sparks, and attack effects are procedural Babylon meshes so input-driven combat stays crisp and responsive.
